# Golden Coast Flyer

An original flight game built for the make.fun competition. Fly along a golden-hour coastline, navigate through glowing target rings, and land safely on the runway!

## Controls
- **Steer / Pitch / Roll**: Arrow keys / WASD or Mouse movement
- **Throttle**: Shift (up) / Ctrl (down), or Plus / Minus keys
- **Boost**: Spacebar
- **Pause / Restart**: P / R keys

## How to Run
1. Start the dev server: `node serve.ts`
2. Open `http://localhost:8080` in your browser.
